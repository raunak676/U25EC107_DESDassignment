# Decoder Design Using Verilog HDL

## Overview

This project implements **2×4 Decoder** and **3×8 Decoder** using different Verilog modeling techniques. The designs were developed to understand the behavior and implementation of combinational circuits in Verilog HDL.

## Modeling Techniques Used

* Behavioral Modeling
* Dataflow Modeling
* Structural Modeling

## Files Included

* 2×4 Decoder (Behavioral, Dataflow, Structural)
* 3×8 Decoder (Behavioral, Dataflow, Structural)
* Testbench
* Simulation Waveform Screenshots
* README.md

## Simulation

The decoder circuits were verified using a testbench by applying all possible input combinations. The generated waveforms were analyzed to confirm the correct activation of output lines corresponding to the given input values.

## Result

The simulation results matched the expected truth tables of both the 2×4 and 3×8 decoders. All implementations produced the correct outputs, validating the functionality of each modeling technique.
