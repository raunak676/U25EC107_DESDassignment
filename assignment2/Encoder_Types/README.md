# Encoder Design Using Verilog HDL

## Overview

This project implements different types of encoders using Verilog HDL, including **BCD Encoder**, **Gray Encoder**, and **Priority Encoder**. The designs were developed to understand the encoding of digital inputs into binary representations and to explore various modeling techniques in Verilog.

## Encoder Types Implemented

* BCD Encoder
* Gray Encoder
* Priority Encoder (8×3)

## Modeling Techniques Used

* Behavioral Modeling
* Dataflow Modeling
* Structural Modeling

## Files Included

* BCD Encoder (Behavioral, Dataflow, Structural)
* Gray Encoder (Behavioral, Dataflow, Structural)
* Priority Encoder (Behavioral, Dataflow, Structural)
* Testbench Files
* Simulation Waveform Screenshots
* README.md

## Simulation

The encoder circuits were verified using testbenches by applying different input combinations and observing the corresponding encoded outputs. The generated waveforms were analyzed to ensure correct functionality for each encoder type.

## Result

The simulation results matched the expected encoding operations of the BCD, Gray, and Priority Encoders. All implementations produced the correct outputs, validating the functionality of the different modeling techniques.
