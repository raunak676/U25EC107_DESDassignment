# Logic Gates Using 2×1 Multiplexer

## Overview

This project implements six basic logic gates using a **2×1 Multiplexer (MUX)** in Verilog HDL. The purpose is to demonstrate how a MUX can be used as a universal combinational logic building block.

## Implemented Gates

* AND Gate
* OR Gate
* NAND Gate
* NOR Gate
* XOR Gate
* XNOR Gate

## Files Included

* Individual Verilog design files for each gate
* Common testbench file
* Output waveform screenshots
* README.md

## Simulation

All gates were verified using a common testbench by applying different input combinations and observing the generated waveforms.

## Result

The simulation results matched the expected truth tables of all six logic gates, confirming the correct implementation of each gate using a 2×1 MUX.
