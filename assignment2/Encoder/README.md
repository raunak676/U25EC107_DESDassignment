# Encoder Design Using Verilog HDL

## Overview

This project implements **4×2 Encoder** and **8×3 Encoder** using different Verilog modeling techniques. The designs were developed to understand the implementation and behavior of combinational logic circuits in Verilog HDL.

## Modeling Techniques Used

* Behavioral Modeling
* Dataflow Modeling
* Structural Modeling

## Files Included

* 4×2 Encoder (Behavioral, Dataflow, Structural)
* 8×3 Encoder (Behavioral, Dataflow, Structural)
* Testbench
* Simulation Waveform Screenshots
* README.md

## Simulation

The encoder circuits were verified using a testbench by applying valid input combinations and observing the corresponding encoded outputs. The generated waveforms were analyzed to ensure correct operation.

## Result

The simulation results matched the expected truth tables of both the 4×2 and 8×3 encoders. All implementations produced the correct encoded outputs, validating the functionality of each modeling technique.
