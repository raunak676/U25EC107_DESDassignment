# Demultiplexer (DEMUX) Design Using Verilog HDL

## Overview

This project implements **1×2 Demultiplexer**, **1×4 Demultiplexer**, and **1×N Demultiplexer** using Verilog HDL. The designs were developed to understand the distribution of a single input signal to multiple output lines based on the select inputs and to explore different modeling techniques in Verilog.

## Modeling Techniques Used

* Behavioral Modeling
* Dataflow Modeling
* Structural Modeling *(for 1×2 and 1×4 DEMUX)*
* Parameterized Design *(for 1×N DEMUX)*

## Files Included

* 1×2 Demultiplexer
* 1×4 Demultiplexer
* 1×N Demultiplexer
* Testbench Files
* Simulation Waveform Screenshots
* README.md

## Simulation

The demultiplexer circuits were verified using testbenches by applying different input values and select line combinations. The generated waveforms were analyzed to confirm that the input signal was correctly routed to the selected output line.

## Result

The simulation results matched the expected behavior of the demultiplexers. The input signal was successfully directed to the appropriate output as determined by the select lines, validating the functionality of the implemented designs.
