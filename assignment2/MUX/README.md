# Multiplexer (MUX) Design Using Verilog HDL

## Overview

This project implements **2×1 Multiplexer**, **4×1 Multiplexer**, and **N×1 Multiplexer** using Verilog HDL. The designs were developed to understand the selection and routing of digital signals using multiplexers and to explore different modeling techniques in Verilog.

## Modeling Techniques Used

* Behavioral Modeling
* Dataflow Modeling
* Structural Modeling *(for 2×1 and 4×1 MUX)*
* Parameterized Design *(for N×1 MUX)*

## Files Included

* 2×1 Multiplexer
* 4×1 Multiplexer
* N×1 Multiplexer
* Testbench Files
* Simulation Waveform Screenshots
* README.md

## Simulation

The multiplexer circuits were verified using testbenches by applying different input combinations and select line values. The generated waveforms were analyzed to confirm that the selected input was correctly routed to the output.

## Result

The simulation results matched the expected behavior of the multiplexers. The output correctly followed the input selected by the select lines for all test cases, validating the functionality of the implemented designs.
