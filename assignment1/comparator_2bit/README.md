**2-Bit Comparator using Verilog**

**Description**

This project implements a 2-bit comparator using Verilog HDL.

**Function**

The comparator compares two 2-bit binary numbers and produces:

* G → A > B
* E → A = B
* L → A < B

**Inputs**

* A[1:0]
* B[1:0]

**Outputs**

* G
* E
* L

* Behavioral Modeling
* Dataflow Modeling
