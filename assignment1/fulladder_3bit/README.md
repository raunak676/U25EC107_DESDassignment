**3-Bit Full Adder using Verilog**

**Description**

This project implements a 3-bit Full Adder using Verilog HDL.

**Function**

The circuit adds two 3-bit binary numbers and produces a 4-bit output.

**Inputs**

* A[2:0]
* B[2:0]

**Output**

* SUM[3:0]

**Modeling Used**

* Behavioral Modeling
* Dataflow Modeling
* Structural Modeling
