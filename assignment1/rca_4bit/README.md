**4-Bit Ripple Carry Adder using Verilog**

**Description**

This project implements a 4-bit Ripple Carry Adder (RCA) using Verilog HDL.

**Function**

The Ripple Carry Adder adds two 4-bit binary numbers along with a carry input.
The carry generated from one stage propagates to the next stage, therefore it is called a Ripple Carry Adder.

**Inputs**

* A[3:0]
* B[3:0]
* Cin

**Outputs**

* SUM[3:0]
* Cout
