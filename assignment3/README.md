# Parameterized Adders in Verilog HDL

## Overview

This project implements four different parameterized adder architectures in Verilog HDL:

1. Ripple Carry Adder (RCA)
2. Carry Select Adder (CSA)
3. Carry Skip Adder (CSKA)
4. Carry Look-Ahead Adder (CLA)

All designs are implemented for N = 16 bits and verified using separate testbenches and simulation waveforms.

---

## 1. Ripple Carry Adder (RCA)

### Description

Ripple Carry Adder is the simplest adder architecture. Each full adder receives the carry generated by the previous stage.

### Working Principle

* Sum is generated using XOR operations.
* Carry propagates sequentially from LSB to MSB.
* Delay increases linearly with the number of bits.

### Advantages

* Simple design
* Requires less hardware

### Disadvantages

* Slow for large bit-widths due to ripple carry propagation

---

## 2. Carry Select Adder (CSA)

### Description

Carry Select Adder improves speed by calculating results for both possible carry inputs (0 and 1) simultaneously.

### Working Principle

* Two parallel additions are performed.
* One assumes Carry-In = 0.
* Another assumes Carry-In = 1.
* A multiplexer selects the correct result based on the actual carry.

### Advantages

* Faster than RCA
* Reduces carry propagation delay

### Disadvantages

* Requires additional hardware
* Higher area consumption

---

## 3. Carry Skip Adder (CSKA)

### Description

Carry Skip Adder improves performance by allowing the carry to bypass selected blocks when propagation conditions are satisfied.

### Working Principle

* Adder is divided into blocks.
* Propagate signals are generated for each block.
* If all propagate signals in a block are high, the carry skips the block.
* Otherwise, normal ripple carry is used.

### Advantages

* Faster than RCA
* Less hardware than CLA

### Disadvantages

* Skip occurs only under specific conditions
* Performance depends on input patterns

---

## 4. Carry Look-Ahead Adder (CLA)

### Description

Carry Look-Ahead Adder reduces carry propagation delay by computing carries in advance using Generate and Propagate signals.

### Working Principle

* Generate Signal:
  G = A · B

* Propagate Signal:
  P = A ⊕ B

* Carries are calculated using look-ahead equations instead of waiting for previous carries.

### Advantages

* Very fast carry generation
* Suitable for high-speed arithmetic circuits

### Disadvantages

* Increased hardware complexity
* More logic gates required

---

## Simulation and Verification

Each adder architecture includes:

* Verilog source file
* Testbench file
* Simulation waveform

The designs were simulated and verified for N = 16 bits using a parameterized implementation.

---

## Conclusion

This project demonstrates different adder architectures and their trade-offs between speed, hardware complexity, and carry propagation delay. RCA provides a simple implementation, CSA and CSKA improve performance using carry optimization techniques, while CLA achieves high-speed addition through parallel carry generation.
